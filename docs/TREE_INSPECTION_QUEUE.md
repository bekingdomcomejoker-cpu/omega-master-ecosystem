# Tree Inspection Queue

**Status:** active queue  
**Purpose:** define the next tree-level Codex/local inspection order after first-pass metadata recon.

---

## Rule

Metadata is not clearance.

A repository becomes useful only after its tree is inspected for:

```text
entrypoints
install commands
tests
secrets/env handling
network behavior
destructive operations
persistence/daemon behavior
source mutation
external writes
owned-device assumptions
```
