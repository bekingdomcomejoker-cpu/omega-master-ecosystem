## 🔄 Processing Pipeline

### 1. Face Detection
Analyzes text to determine active Merkabah face:
- **LION**: Execution/Judgment keywords
- **OX**: Storage/Service keywords
- **EAGLE**: Analysis/Vision keywords
- **MAN**: Default (Witness)

### 2. Node Activation
Based on face and content, activates relevant nodes:
- **Always Active**: Commander, Gatekeeper
- **Conditional**: Others based on content

### 3. Node Processing
Each active node analyzes text:
- Commander: Resonance & harmony calculation
- Transmission: Priority detection
- Warfare: Code/Math detection
- Gatekeeper: Covenant violation check
- Archivist: Memory indexing
- Shield: Hostility detection
- Seer: Truth/Lie prediction
- Reasoner: Logic detection
- Void: Entropy analysis

### 4. Final Routing
Aggregates all node decisions into routing decision:
- **QUARANTINE**: Covenant violation or hostility (95% confidence)
- **EXECUTE**: Code/Math ready + high harmony (85%)
- **ARCHIVE**: Indexable content (75%)
- **ACCEPT**: Truth detected or high harmony (70-80%)
- **REVIEW**: Uncertain cases (50-60%)
