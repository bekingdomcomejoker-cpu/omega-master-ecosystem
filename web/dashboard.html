🔐 Key Concepts

Single Source of Truth

terex.py is the only source of truth. All logic is deterministic and reproducible.

Deterministic Registry

Same input always produces same hash. Registry is reproducible and auditable.

SHA-256 Integrity

Every payload and entry is cryptographically verified. No tampering possible.

Append-Only Growth

Registry can only grow, never be modified. Pre-commit hook enforces this.

CI Enforcement

Pre-commit hooks verify integrity. No manual steps after setup.

Zero Magic

No randomness, no timestamps in hashes. Everything is deterministic.
