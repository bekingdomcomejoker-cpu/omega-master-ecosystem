## Installation

```bash
chmod +x scripts/install_placement.sh
./scripts/install_placement.sh
```

## Usage

```bash
# Analyze query and suggest model
llm-placement analyze "your query"

# Get placement recommendation
llm-placement recommend

# Optimize for latency
llm-placement optimize latency

# Optimize for cost
llm-placement optimize cost

# Show model comparison
llm-placement compare

# Monitor placement
llm-placement monitor
```

## Model Selection Algorithm

```
1. Analyze query complexity
2. Estimate context requirement
3. Check resource availability
4. Match to optimal model
5. Apply fallback if needed
6. Monitor performance
7. Adjust strategy
```
