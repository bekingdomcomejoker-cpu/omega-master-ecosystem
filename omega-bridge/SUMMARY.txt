                              WHAT IS OMEGA BRIDGE?
================================================================================

OMEGA BRIDGE is a real-time command execution system that connects your Redmi
13C Termux environment to Manus (cloud) for remote command execution.

Key Features:
  ✅ Real-time bidirectional communication
  ✅ No API credits required (uses WebSocket)
  ✅ Multiple session support
  ✅ Command history and tracking
  ✅ Connection status monitoring
  ✅ Error handling and recovery
  ✅ Termux-compatible
  ✅ Production-ready
  ✅ Comprehensive documentation

================================================================================
                            KEY ENDPOINTS
================================================================================

REST API:
  POST   /api/session/create              Create a new session
  GET    /api/sessions                    List all sessions
  GET    /api/session/:sessionId          Get session details
  GET    /api/session/:sessionId/commands Get session commands
  GET    /health                          Health check

Socket.IO Events:
  termuxConnect       → Authenticate listener
  termuxOutput        → Send command output
  dashboardCommand    → Send command from dashboard
  executeCommand      → Receive command to execute
  sessionStatusChanged → Broadcast status changes
  commandOutput       → Broadcast command output
  commandStatusChanged → Broadcast command status

================================================================================
                            SECURITY NOTES
================================================================================

⚠️ Current Implementation:
   - No user authentication
   - Connection tokens are simple random strings
   - All sessions visible to anyone with the URL

🔒 Best Practices:
   - Keep the dashboard URL private
   - Don't share connection tokens
   - Monitor what commands are executed
   - Use on private networks if possible

For Production:
   - Add user authentication
   - Implement stronger token generation
   - Add rate limiting
   - Use HTTPS/WSS only
   - Add input validation

================================================================================
                            TROUBLESHOOTING
================================================================================

Dashboard won't load
  → Check internet connection
  → Try refreshing the page
  → Check if server is running

Listener won't connect
  → Verify URL is correct
  → Check connection token is exact
  → Verify Termux has internet access
  → Check Node.js is installed

Commands not executing
  → Verify session status is "connected"
  → Check if listener is still running
  → Try a simple command first

No output appearing
  → Some commands produce no output
  → Try a command that produces output
  → Check if command is hanging
  → Check browser console for errors
