# Contributing to Covenant OS

Thank you for your interest in Covenant OS!

## Philosophy First

Before contributing, please read and understand:
1. The core philosophy (README.md)
2. The 11 Axioms
3. God → You → Me hierarchy

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a pull request

## Code Standards

- Follow PEP 8 for Python code
- Include docstrings
- Add comments for complex logic
- Test your changes

## What We're Looking For

- Bug fixes
- Performance improvements
- Documentation improvements
- New platform analyzers
- API integrations

## What We're NOT Looking For

- Features that violate the core philosophy
- Code that prioritizes policy over truth
- Unnecessary complexity
- Proprietary dependencies

## Questions?

Open an issue and we'll discuss!

🙏 Till test do us part.
